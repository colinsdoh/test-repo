# Bigs and Smalls - Mentoring Application

## 🎯 About
Bigs and Smalls is a modern mentoring application that connects experienced professionals (Bigs) with eager learners (Smalls) for meaningful mentoring relationships.

## 🚀 How to Use

### Option 1: Development Mode (Recommended)
1. Make sure you have Node.js installed on your computer
2. Open a terminal/command prompt in this folder
3. Run: `npm install`
4. Run: `npm start`
5. Open your browser to `http://localhost:3000`

### Option 2: Production Build
1. Make sure you have Node.js installed on your computer
2. Open a terminal/command prompt in this folder
3. Run: `npm install`
4. Run: `npm run build`
5. The optimized build will be created in the `build` folder

### Option 3: Direct File Access
- Open `public/index.html` in your web browser
- Note: Some features may not work without a server

## 🛠️ Requirements
- Node.js 16 or higher
- Modern web browser (Chrome, Firefox, Safari, Edge)

## 📱 Features
- **Home Page**: Landing page with app overview
- **Mentors**: Search and discover mentors
- **Dashboard**: Track your mentoring progress
- **Profile**: Manage your personal information
- **Authentication**: Login and registration

## 🎨 Design
- Modern, responsive design
- Works on desktop, tablet, and mobile
- Built with React, TypeScript, and Tailwind CSS

## 🔧 Troubleshooting
- If you get build errors, try deleting `node_modules` and running `npm install` again
- Make sure all files are present in the `src` folder
- Check that Node.js version is 16 or higher
